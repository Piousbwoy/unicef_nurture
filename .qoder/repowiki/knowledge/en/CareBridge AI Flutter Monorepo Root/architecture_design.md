The root `pubspec.yaml` declares the single `carebridge_ai` package (Flutter SDK ^3.10.0) whose dependencies — Riverpod, go_router, sqflite, flutter_secure_storage, connectivity_plus, audioplayers, qr_flutter, etc. — are shared across all child modules. The Android (`android_platform`) and iOS (`ios_platform`) directories are the native runners that embed this same Dart package via the Flutter engine, while the `lib_application` module provides the cross-platform Dart code and the `tests` module asserts its behaviour. There is no separate orchestrator binary; the app entry point lives in the Dart layer and is launched by each platform shell, so the root's role is purely dependency and asset declaration plus global linting via `analysis_options.yaml`.
