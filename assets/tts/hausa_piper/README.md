# Hausa Piper TTS Model (On-Device)

Place the Murya Piper model files here:
- model.onnx (~77 MB, multi-speaker VITS)
- model.onnx.json (config with phoneme_id_map, sample_rate)

Download:
    huggingface-cli download adab-tech/murya-piper-hausa-tts --local-dir assets/tts/hausa_piper

Model: Murya (CC-BY-NC-SA-4.0) — 8 native Hausa speakers, WAXAL corpus, 24 kHz.
Speaker 0: "Malam Garba" (male, Standard Kano dialect).
